PROTOCOL IMPLEMENTATION
-----------------------

Request Format:
  Byte 0: 0xA5 (marker)
  Byte 1: 0x01 (version)
  Byte 2: sequence number
  Byte 3: opcode (01-05)
  Byte 4: payload length (0-9)
  Bytes 5+: payload
  Last: CRC-8

Response Format:
  Byte 0: 0x5A (marker)
  Byte 1: 0x01 (version)
  Byte 2: sequence number
  Byte 3: opcode | 0x80
  Byte 4: length (status + data)
  Byte 5: status code
  Bytes 6+: data
  Last: CRC-8

CRC Verification:
- Polynomial: 0x07
- Init: 0x00
- Check value: 0xF4 for "123456789" ✓ Implemented
- Excludes marker and CRC bytes

Commands Implemented:
1. PING (0x01) - Verify FPGA communication, return version
2. CONFIG (0x02) - Set rotors, windows, rings (9 bytes)
3. TRANSFORM (0x03) - Encrypt/decrypt single contact
4. READ_STATE (0x04) - Get current window positions
5. RESET (0x05) - Reset FPGA to default state

Error Handling:
- Invalid JSON: {"status": "error", "error": "Invalid JSON"}
- FPGA timeout: {"status": "error", "error": "FPGA timeout"}
