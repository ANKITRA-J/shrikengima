PIN MAPPINGS (from Specification Section 2)
-------------------------------------------

Runtime UART Interface (ESP32-S3):
  - FPGA Pin 5 (Input)  <- ESP32-S3 GPIO11 (TX)
  - FPGA Pin 6 (Output) -> ESP32-S3 GPIO13 (RX)
  - Protocol: 115200 baud, 8N1, CLKS_PER_BIT=434

Clock and Control:
  - OSC_CLK (Input)  - 50MHz clock source
  - OSC_EN (Input)   - Clock enable signal

LED Output:
  - GPIO16 (Output)     - LED data signal
  - GPIO16_OE (Output)  - LED output enable (set to 1)

TIMING ANALYSIS
---------------

Critical Paths (predicted):
1. Rotor ROM lookup -> Arithmetic -> Next state register
   Estimate: <15ns (meets 20ns @ 50MHz)

2. UART bit counter -> State machine -> TX shift register
   Estimate: <10ns (meets 20ns @ 50MHz)

3. CRC calculation -> Packet FSM -> Response builder
   Estimate: <12ns (meets 20ns @ 50MHz)

UART Baud Rate Accuracy:
  - Configured: CLKS_PER_BIT = 434
  - Actual baud: 50,000,000 / 434 = 115,207.37 baud
  - Error: +0.063% (well within ±3% UART tolerance)
